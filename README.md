# Console-Based Tic-Tac-Toe Game (C++)

A clean, interactive, and lightweight implementation of the classic Tic-Tac-Toe game, written entirely in C++. This project operates directly in the console, featuring a two-player turn-based system, real-time board rendering, and automated win/draw detection.

## 🚀 Features
* **Interactive 2-Player Gameplay:** Turn-based mechanics for Player X and Player O.
* **Input Validation:** Prevents players from selecting already occupied cells or entering out-of-bounds coordinates.
* **Smart Game Loop:** Automatic checking for win conditions (rows, columns, diagonals) and draw scenarios.
* **Data Efficiency:** Built using structured data components to keep memory overhead minimal and performance fast.

## 🛠️ Concepts Applied
* Array/Matrix manipulation for the game board grid.
* Conditional logic and loops for the game engine execution.
* Clear, modular function design for code readability and maintenance.
